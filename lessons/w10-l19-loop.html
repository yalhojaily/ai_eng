Answer to last lesson's question. The fixed sequence "retrieve, then answer" would have to become a decision made at run time: after each lookup, something must judge whether enough is known, and if not, choose the next lookup based on what was just found. Hand that judgement to the model, inside a loop, and you have an agent.

1. Workflows and agents

Lesson 8's chains are workflows: the steps and their order are written in your code, and the model fills in each step. In an agent, the model decides what to do next, using tools, repeatedly, until it judges the task done. Three ingredients, all of which you already have:

  • a model that can request tools (Lesson 4);
  • a set of tools, ordinary functions with descriptions;
  • a loop that runs the requested tool, appends the result to the conversation, and asks the model again.

The difference is who holds the steering wheel. That buys flexibility: an agent can handle questions whose solution path you could not have written down in advance. It costs predictability, and this phase is largely about getting that back.

2. This phase's subject: corpus linguistics

The agent you will build does a linguist's job. Corpus linguistics studies language by examining large collections of real text, called corpora, instead of consulting intuition. Asked how a word is used, a corpus linguist does not introspect. They look, with three basic instruments:

  • a concordance: every occurrence of a word, each shown with a little context on either side, lined up on the word itself. This layout is called KWIC, "key word in context". Reading down the column, patterns jump out that no single sentence shows;
  • frequency: how often the word occurs, overall and in different kinds of text;
  • collocation: which other words turn up near it more often than chance would predict.

These are the agent's tools. Try the first one yourself on a miniature corpus of 45 sentences in three genres, written for this course.

3. The loop

messages = [system, question]
repeat:
    reply = model(messages, tools)
    append reply to messages
    if reply has no tool calls:  stop, reply is the answer
    for each tool call:
        result = run the tool
        append result to messages

That is Lesson 4's tool loop, unchanged. Each trip round has three phases, often called think, act, observe: the model reasons about what it knows and needs, requests a tool, and reads the result. Then it thinks again, with one more fact in hand.

Notice: nobody told the agent to check frequency before reading examples, or to look at the two genres separately. Those were its choices, and the second lookup depended on the first result. Also watch the counter: the request grows at every step.

4. The agent's whole mind is the message list

Recall Lesson 3: the model keeps nothing between requests. An agent's memory of what it has done is the list of messages, re-sent in full at every step. Two consequences follow, and they shape the next five lessons.

  • Cost grows faster than the number of steps. Step ten re-sends the results of steps one to nine. A run of twenty steps can bill many times the tokens of its final answer.
  • Tool results dominate the context. The question is a sentence, the reasoning a few lines, and a careless tool can return thousands of tokens. What your tools return is, in effect, what your agent thinks about. Lesson 20 is about that.

5. Stopping

The loop above ends when the model replies without requesting a tool. Nothing guarantees that will happen. An agent can keep searching for something that is not there, or call the same tool again and again. So every real loop has hard limits enforced by your code, not by the model's judgement:

  • a maximum number of steps;
  • a budget in tokens or money;
  • a time limit.

When a limit is hit, stop and say so, returning whatever was found along with a clear statement that the run was cut short. An agent that silently runs for an hour is a bill. One that silently stops halfway and presents its partial work as complete is worse.

6. When an agent is the right tool

Lesson 8's rule still holds: start with the simplest thing. Use a single call if it works, a workflow if the steps are known. An agent earns its cost when the path really cannot be fixed in advance, the task tolerates some variation in how it is done, and a wrong step can be noticed and corrected.

Lab: your first agent

Time: 90 minutes. pip install nltk. The corpus is the Brown corpus, a million words of American English from 1961 sorted into genres, which NLTK can download.

import json, nltk
nltk.download("brown")
from nltk.corpus import brown

GENRES = ["news", "fiction", "learned", "romance", "government"]
SENTS = {g: [" ".join(s) for s in brown.sents(categories=g)] for g in GENRES}
WORDS = {g: [w.lower() for w in brown.words(categories=g)] for g in GENRES}

def concordance(word, genre, limit=8):
    lines = [s for s in SENTS[genre] if f" {word.lower()} " in f" {s.lower()} "]
    return {"genre": genre, "total": len(lines), "shown": lines[:limit]}

def frequency(word):
    out = {}
    for g in GENRES:
        n = WORDS[g].count(word.lower())
        out[g] = {"count": n, "per_million": round(n / len(WORDS[g]) * 1_000_000)}
    return out

FUNCTIONS = {"concordance": concordance, "frequency": frequency}
TOOLS = [
    {"type": "function", "function": {
        "name": "concordance",
        "description": "Show sentences from one genre of the corpus that contain the exact word form.",
        "parameters": {"type": "object", "properties": {
            "word": {"type": "string"},
            "genre": {"type": "string", "enum": GENRES},
            "limit": {"type": "integer", "description": "Maximum sentences to return (default 8)"}},
            "required": ["word", "genre"]}}},
    {"type": "function", "function": {
        "name": "frequency",
        "description": "Count an exact word form in every genre, raw and per million words.",
        "parameters": {"type": "object", "properties": {"word": {"type": "string"}},
                       "required": ["word"]}}},
]

def run_agent(question, max_steps=8):
    messages = [
        {"role": "system", "content": "You are a corpus linguist. Answer questions about word "
         "usage only from evidence you obtain with the tools. Quote the sentences you rely on."},
        {"role": "user", "content": question},
    ]
    for step in range(1, max_steps + 1):
        r = client.chat.completions.create(model=MODEL, messages=messages, tools=TOOLS)
        msg = r.choices[0].message
        messages.append(msg)
        print(f"--- step {step}: {r.usage.prompt_tokens} input tokens")
        if not msg.tool_calls:
            return msg.content
        for call in msg.tool_calls:
            args = json.loads(call.function.arguments)
            print("   call:", call.function.name, args)
            result = FUNCTIONS[call.function.name](**args)
            messages.append({"role": "tool", "tool_call_id": call.id,
                             "content": json.dumps(result)})
    return "Stopped: step limit reached before an answer was produced."

print(run_agent("Is 'run' used differently in news and in fiction?"))
